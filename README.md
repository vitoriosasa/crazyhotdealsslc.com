# Sagebrush Furniture — Furniture Showcase Site

A local furniture showcase site: catalog home page + item pages + digital business card + Marketplace listing-text generator + admin panel.
Lead generation and sales still happen on Facebook Marketplace / Messenger — the website only showcases and routes buyers to you.

Brand: Sagebrush Furniture · sagebrushfurniture.com · Warehouse pickup in the Salt Lake City area

## Run

```bash
npm install     # first time
npm start       # defaults to http://localhost:3000
```

Change port: `PORT=8080 npm start`

## First use

1. Open `/admin` and set the admin password (one time only).
2. Under "Site details", confirm **Public website address** is `https://sagebrushfurniture.com`
   — the card QR code and all share links use it; a wrong value means scanned links won't open.
3. Fill in Facebook / Messenger links and categories.
4. "+ New item" — upload photos, set price / dimensions / condition / **what's included** / **what's NOT included** — saving publishes it.
5. Share: `/p/<item-id>` (item page), `/card` (digital card with QR code).

## Pages

| Path | What it is |
|---|---|
| `/` | In-stock catalog: search, category filter, price sort, New badges |
| `/p/<id>` | Item page: multi-image lightbox, quantity, specs, three contact buttons |
| `/card` | Digital business card, printable directly (browser Ctrl+P) |
| `/listing/<id>` | One-click Marketplace title / description / photo downloads |
| `/admin` | Admin panel (password required) |
| `/sitemap.xml` `/robots.txt` | For search engines |

## Full workflow for listing one piece

1. `/admin` → "+ New item" → upload photos, fill in details → save
2. Click **Listing text** on the item row → copy title, copy description, download photos
3. Open Facebook Marketplace, paste and upload the photos
4. Back on the listing page, paste your Marketplace link → "Save link & mark as posted"
5. When it sells, click **−** in `/admin` to reduce stock; reaching 0 automatically marks it Sold
6. A "Take these down on Marketplace" reminder appears at the top of the admin panel → remove it on Facebook → click "Done — removed"

## Stock & log

- Every item has a `quantity`. "3 in stock" tells buyers there are 3 pieces — visible to them.
- The **− / +** buttons in admin change quantity; every change is recorded in "Recent stock changes" with time, amount, and reason.
- Quantity reaching 0 → automatically marked **Sold**; adding quantity back → automatically **Available** again.
- Sold items stay visible on the site for **7 days**, then auto-hide, so old links never land on a blank page.
- Items listed within the last 7 days get a **New** badge on the home page.

## Where the data lives

```
data/
├── products.json     item data
├── site.json         site info + admin password hash
├── stock-log.json    stock change log
├── .secret           session signing key
└── uploads/          item photos
```

Backup = copy the whole `data/` directory, or click "Download backup (JSON)" in admin. Deleting `data/` wipes everything.

**Restore**: admin → "Backup → Restore from a backup file", pick the JSON. The password is not overwritten.

## Boundaries

- No shopping cart, no online payment, no automatic shipping, no buyer accounts — deliberate.
- Single admin, single instance; no simultaneous multi-user editing.
- Marketplace text is generated by the tool; **publishing is still done by you** on Facebook (avoids account risk flags).
- The site is English-only by design.
